打分维度定义 (12 项)

1. 概念规律数 (concept · 1 - 5)
学生要用到多少个独立的物理规律 / 定律 / 公式族才能解出这题。同一规律的不同代数形式算 1 个。
· 1 = 直接套一个公式
· 2 = 一个规律 + 一步选路径 / 几何抽取
· 3 = 两三个规律串联
· 4 = 多规律联立 + 交叉主题
· 5 = 复合场 · 多阶段 · 多物体 联立
2. 推理步数 (reasoning · 1 - 5)
从题目条件到答案 · 学生大脑里要走多少个推理步骤。可以数"因为...所以..."的层数。
3. 情境新颖度 (novelty · 0 - 3)
题目情境与教材 / 常见练习的差异程度。
· 0 = 教材原题级熟悉
· 1 = 常见变形
· 2 = 情境陌生但物理熟悉
· 3 = 情境和物理都新颖
4. 视觉复杂度 (visual · 0 - 2)
题目图 / 表 / 图像的信息密度。
· 0 = 无图
· 1 = 简单示意图
· 2 = 需从复杂图 / 图像提取多个数据
5. 建模自主度 (modeling · 0 - 3)
题目要求学生自主建立物理模型的程度。
· 0 = 题目已给全部理想化条件
· 1 = 需要选合适模型
· 2 = 需要抽象出关键假设
· 3 = 需要从头建模 + 数学构造
6. 场景相似度 (textbook_scene · 0 - 2)
题目物理场景 / 装置与教材例题的相似程度。
· 0 = 完全陌生的场景 (教材没出现过)
· 1 = 教材场景的明显变形
· 2 = 教材场景直接对应
7. 模式相似度 (textbook_pattern · 0 - 2)
题目解题模式与教材训练的相似程度。
· 0 = 需要自主建模 / 类比推理 / 数学构造
· 1 = 教材模式的小改造 (需要跨章联立 / 图像技巧等)
· 2 = 教材训练过的模式直接可套
8. 陷阱数 (trap_count · 0 - 3)
触发学生常见失分点 (misconception zone) 的个数。触发几个失分点就打几分。核心是"学生真会犯的错" · 不是"物理上有多少种错法"。
9. 大题子问 (is_open · 0 / 1)
是选择题 = 0 · 是解答题 (大题小问) = 1
10. 话题 (topic)
力学 · 电磁 · 热光近代 三选一 (可写"力" · "电" · "热光" 简称)
11. 题号位置 (position · 客观 · 我这边算 · 您不用打)
题号 / 总题数 · 归一到 0-1
12. 前段累积概念载荷 (earlier_load · 客观 · 我这边算 · 您不用打)
题号之前所有题的平均概念数
共 12 维 · 位置和前段载荷两项客观自动计算 · 实际需要您判断的是前 10 项。
