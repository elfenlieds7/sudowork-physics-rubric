先说清楚几个统计术语 (以下都是模型评估通用词, 不是物理术语):
MAE (平均绝对误差)
模型预测值与真实值差的绝对值取平均。当前单题 MAE = 0.057 意思是"平均每道题的预测得分率与实际学生得分率差 ±5.7 个百分点" (西城尺度)。
R² (决定系数)
模型解释真实数据波动的比例, 取值 0-1, 越接近 1 越准。当前单题 R² ≈ 0.89 意思是"模型解释了 89% 的题间难度波动"。
留一试卷交叉验证 (LOPO, Leave-One-Paper-Out)
把 7 套试卷里的 1 套完全从训练集拿出去, 用剩下 6 套训练模型, 再让模型预测被拿出去那套。依次换 7 次每套都被"当过测试集"。模拟"出一份新卷子, 用历史数据预测其难度"这个真实场景。上文所有 MAE / R² 都是 LOPO 数值 (out-of-sample)。
整卷加权 MAE
把单题预测按分值权重加起来算整卷得分率, 与实际整卷得分率比。因为单题误差在整卷聚合时高估低估互相抵消 (中心极限效应), 整卷 MAE (1.53 pp) 远小于单题 MAE (5.7 pp), 缩小约 4 倍。
样本群 (cohort)
参加考试的学生群体。本项目训练集全是"西城区学生"cohort. 全北京 cohort 更宽 · 得分率通常比西城低 5-8 个百分点 (见 §5.8 校准模型). 未来所有预测默认输出西城尺度 · 需要全北京 truth 时用 M3 偏移模型转换.
过拟合
模型在训练数据上表现好, 但换成没见过的新数据就崩了。LOPO 就是防过拟合的主要手段。第二部分给了 4 项额外的过拟合检验。

1.2 · 命题工具实用意义

核心用途: 命题老师出好一份新卷子, 按评分表给每题打 14 维分数, 模型立即输出:
  1. 整卷预测得分率 (误差通常 1-2 pp · 最大 2.7 pp)
    · 预测 < 0.65: 卷子偏难 · 建议替换 1-2 道最难题
    · 预测 0.65-0.75: 难度合适
    · 预测 > 0.75: 卷子偏容易 · 可加难 1-2 道
  2. 逐题预测得分率 (误差 ~6 pp) · 沿题号排序画曲线 · 检查是否符合您理想中的"三段递增"结构 (选择题递增 / 15-16 递增 / 17-20 递增)
  3. 异常题预警: 预测得分率与后续实际差异大的题 · 通常是评分表没覆盖的因素 (陷阱数 · 新维度) · 值得回头分析
相比经验拍板判断难度, 这个工具能量化, 不依赖个人主观, 也能持续跟真实高考数据校准 (docx 场景三).

五 · 探索历程 (关键决策与发现)

下面按时间顺序梳理 · 每个 subsection 只保留结论, 详细过程见 GitHub commit 历史.

5.1 · 三届学生届次波动微乎其微 (2026-08-02 上午)

杨老师 8:19 微信确认 "5000+ 人整体稳定". 数据侧算: 7 份试卷整卷均分范围 0.663-0.726 · 跨试卷 SD 只有 0.024. 结论: 学生届次差异远小于试卷内的题间难度差异. 建模时不需要额外届次校正 (试过 3 种校正方案, 都无收益).

5.2 · 场景 / 模式相似度 · A+B 拆分 + label bias 修正

杨老师 8:17 微信 "典型模型 = A+B" 之后, 拆成两维. 初期 v2 数据显示 "场景系数 ≈ 0, 只有模式有信号", 但杨老师 11:24 反对: 场景熟悉降低难度是真实的 (霍尔推进器例子). 加入迁移成本交叉特征 (= 模式 − 场景) 后, 场景系数从 +0.0003 恢复到 +0.026. 也印证 label bias: 若人工评分时把"陌生场景"的罚分算进 concept/modeling, 场景本身的独立信号被抢走.

5.3 · 建模难度交互项 · 学生卡步骤 2 (2026-08-02 晚)

杨老师 20:58-21:00 给出学生解题 4 步骤 taxonomy (读题 · 建模 · 选规律 · 求解), 明确 "学生常卡在步骤 2 建模, 压轴题难在建模上". 数据侧加了 建模×新颖 + 建模×大题 + 概念×建模 三个交互项. 单项 LOPO MAE 从 0.076 → 0.068, 大题最后小问 (Pattern A) 预测偏差显著改善.

5.4 · 位置与内容难度的统计解耦

Ethan 20:15 shareone 评论指出 "位置" 和 "内容难度" 天然共线 (命题者按难度递增排题). 位置 91% 变化被内容特征解释. 试验后决定保留位置特征 · 因为位置可能有正交的时间压力贡献 · 在样本量扩大后可能能干净分离. 当前删或留 LOPO MAE 差异在噪声范围内 (± 0.002).

5.5 · 陷阱数 · 老师 review 后加入 · 20.8% 误差削减

杨老师 13:06 提出陷阱数假设 (陷阱数 ≈ f(概念数) · 可能合并). 8-3 上午在 shareone 亲自 review 我 pre-label 的 30 道题, 详细给出严格版陷阱数 + A-G 依据. 数据侧验证:

  • 合并版 (陷阱数 + 概念数 单一特征): MAE 0.058 · 验证她的合并假设
  • 独立版 (陷阱数独立特征): MAE 0.058 · 与合并版相同
  • 只用陷阱数替代概念数: MAE 0.061 · 差 · 说明两者各有独立信号
  • r(陷阱数, 概念数) 从我 pre-label 时的 0.72 降到她严格版的 0.47 · 陷阱数 78% 独立方差

加入陷阱数后 · 单题 MAE 从 0.062 → 0.058 (最大单一 gain). 也印证 Ethan 17:02 的 interpretation: 陷阱不是"刻意设计干扰项", 是知识关联性引发的错误路径.

5.6 · 集成 (Lasso + GBM) 突破线性天花板

Ethan 13:03 push "让 AI 换几个模型试试" · 试了 10+ 种. 单模型天花板 0.062-0.066 (线性 Ridge / Lasso / 树 GBM / XGB / LGB / RF / kNN / SVR). Lasso + GBM 等权集成突破到 0.062 (Lasso 学线性, GBM 学非线性组合, 两者互补). 加陷阱数后共同到 0.058. 试过 stacking, 加权优化, bag-of-GBMs, 都无明显提升.

5.7 · 跨试卷种类泛化 pilot (docx 场景三)

杨老师 docx 里的场景三: 用未来高考数据反向验证. 试过: 只用 3 份西城模拟卷训模型 · 完全 hold out 高考数据 (63 道) · MAE = 0.079, R² = 0.83. 只掉 2-3 个百分点 · 说明评分表抓到"物理题目通用难度信号", 不只 fit 西城 baseline. 小样本 cohort 校准 (用 3 道该区实际数据反推 baseline) 有帮助 · 未来跨区域应用可行.

5.8 · 跨样本群校准 · 西城 ⇌ 全北京 (2026-08-04 晚新增)

触发: 杨老师 08-04 早上发一道验证题 · 报了得分率 59%. 我模型预测 58.6% · 看似神预测 (0.4 pp) · 但杨老师随后澄清: 训练集全是西城学生 · 验证题真值是全北京. 两个尺度不同. 深入分析后发现"神预测"是两个方向相反的误差 (陷阱数打分偏高 · 样本群尺度差异) 恰好抵消的巧合. 详见 [诊断脚本].

杨老师当晚发来 3 份表 (2023、2024、2025 高考各小题 西城 + 全北京 得分率对照 · 由她从教研数据源摘录 · 保密处理 · 不出具体数字), 共 121 对 (西城, 全北京) 配对. 在此上拟合 4 个偏移模型 · 交叉验证选最佳:

M0 常数β京 = β西 + c2.12 ppc = −6.5 pp

  • 极难题段 (西城 < 0.5 · n=22): 差 −6.7 pp · 两边都低 · 差距压不出来
这个规律非常稳定 · 从 2 年数据 (82 对) 到 3 年 (121 对) · 系数只微调 · 说明不是 fluke.

回头看 08-04 早上气泡上浮验证题 · 现在能给"干净"的评估:

  • 全北京 truth = 59%
  • M3 反推西城 truth ≈ 59 + 8.2 = 67.2% (气泡上浮题 · 中难段)
  • 杨老师直觉 西城 = 65%
  • 模型预测 (陷阱数修正后 · 西城尺度) = 66%
  • 三个数字相差 ≤ 2.4 个百分点 · 排除样本群差异和 label 误差后 · 模型在西城尺度上确实校准良好 · 这才是 clean validation.

方法论 lesson: 外部验证不能只看 |truth − predict| · 必须拆开三个误差源 (打分误差 + 样本群尺度差 + 模型残差). 一个数据点两误差抵消可以造成假象 · 让人错误相信"精准"或"崩了". 本次教训已写入项目 memory · 未来验证按此协议.

陷阱数定义 (采用杨老师 18:13 的说法):
一道题里, 触发学生常见失分点 (misconception zone) 的个数。触发几个失分点就打几分, 一般 0 到 3 之间。
  • 0 = 该题内容没触发学生常见失分点
  • 1 = 触发一个 (比如竖直方向运动 → 学生易丢重力)
  • 2 = 触发两个 (比如矢量+竖直方向 → 忽略方向 + 丢重力)
  • 3 = 触发三个或以上
常见失分点候选清单 (源自杨老师 18:13, 打分时可参照):
  • A · 竖直方向运动丢重力
  • B · 矢量问题忽略方向 (正负号 / 方向)
  • C · 温度与热量概念混淆
  • D · 忽视功的正负
  • E · 忽视有效数字位数
  • F · 算术错误 (比例 / 单位换算 / 代入错)
  • G · 其他 (您觉得的其他常见错)
为什么选这 30 道: 从当前 v4 评分表预测残差最大的题里挑 · 前 20 道是选择题 (每份试卷 4 道) · 后 10 道是大题小问 (每份试卷 2 道) · 都是模型现在解释不了的题目, 陷阱数最可能解释这里。
三个数字含义: 实际得分率 = 您红笔标注的; v4 预测 = 当前模型给出的; 残差 = 实际减预测 (正数说明我低估了难度, 负数说明我高估了)。
