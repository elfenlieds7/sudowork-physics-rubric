📋 v2 完整维度: 10 项打分 · 分 3 大类
您需要独立打的是 10 维 (前 10 项) · 无客观自动项

🧭 大类 1: 情境信息 (输入)

1情境特征 (context_familiarity · 3 档)
题目情境与学生已见过的教材/常规练习的熟悉程度。合并了原 v1 的"情境新颖度"和"场景相似度"两维。
  • 0 · 熟悉情境: 教材原题级 · 装置和例题习题直接对应
  • 1 · 半陌生情境: 教材场景的明显变形 · 换外壳、加约束
  • 2 · 完全陌生情境: 教材没出现过的场景
示例:
· 0 = 高考 2025 Q1 古代点火器（教材热学 + 力做功经典情境）
· 1 = 西城 2025 Q3 庆典气球上升（气体上升教材经典 · 但换到气球场景）
· 2 = 高考 2024 Q20 天宫霍尔推进器（航天推进 · 教材无对应）
2信息呈现 (info_complexity · 3 档)
题目通过图 / 表 / 图像给出信息的复杂程度。对应 v1 的"视觉复杂度"。
  • 0 · 无图: 纯文字题
  • 1 · 简单示意图: 帮助理解 · 无需从图提取数据
  • 2 · 复杂图信息: 需要从图/图像提取多个数据点 · 如 v-t 图判读、复杂电路图
示例:
· 0 = 高考 2024 Q1 半衰期（纯文字）
· 1 = 高考 2022 Q5 斜面上物块受力（简单力示意图）
· 2 = 高考 2023 Q4 简谐横波 t=T 时的波形图（4 选 1 波形对比 · 需读多组图）

📚 大类 2: 学科知识 (知识储备)

3模块属性 (topic · 3 类)
题目主要考察的物理模块。
  • 力学: 运动学 / 力 / 动量 / 能量 / 机械振动
  • 电磁: 电场 / 磁场 / 电路 / 电磁感应 / 交流电
  • 热光近代: 热学 / 光学 / 原子物理 / 相对论 / 核物理
4知识点数 (concept_count · 5 档 · 原名"概念规律数")
学生要用到多少个独立的物理规律 / 定律 / 公式族才能解出这题。F=ma 记 1 个知识点 · 运动学公式记 1 个知识点。同一规律的不同代数形式算 1 个。
  • 1: 直接套一个知识点（如半衰期公式 · 光的现象判定）
  • 2: 一个知识点 + 一步选路径 / 几何抽取（如匀变速运动 + 选择公式）
  • 3: 两三个知识点串联（如气泡上浮: 理想气体 + 液体压强 + 第一定律）
  • 4: 多知识点联立 + 跨模块（如带电粒子在磁场中的运动: 洛伦兹力 + 圆周运动 + 能量守恒）
  • 5+: 复合场 · 多阶段 · 多物体联立（大题最后小问常见）
示例:
· 1 = 高考 2024 Q1 半衰期（半衰期公式 1 个）
· 2 = 汽车匀减速制动（匀变速运动 1 + 选平均速度或运动学公式）
· 3 = 气泡上浮（理想气体等温 + 液体压强 + 第一定律）
· 4 = 电磁感应大题主问（法拉第 + 楞次 + 欧姆 + 焦耳）
· 5 = 复合场带电粒子最后小问（洛伦兹 + 电场力 + 能量 + 几何 + 数学）
5知识深度 (knowledge_depth · 4 档 · v2 新增)
对物理概念 / 规律理解的深度要求。只和知识内容挂钩，和"怎么搭建模型"无关。打学生能达到的最高层级（杨老师 18:31）。
  • 记忆识别: 识别现象名字 / 记住公式 / 背概念定义
  • 基础理解: 理解概念内涵 · 能用一个公式解决直接问题
  • 常规应用: 能把几个概念组合起来解常规问题 · 有教材训练过的解题套路
  • 综合分析: 需要跨概念、跨模块综合 · 或需要在多种可能中判断选取 · 或需要迁移创新
示例:
· 记忆识别 = 高考 2025 Q1 古代点火器（记住"绝热压缩 → 内能↑ → 温度↑ → 点燃"）
· 基础理解 = 高考 2022 Q3 理想气体 pV 图判过程（理解 pV 图各段含义）
· 常规应用 = 匀变速制动求距离（应用匀变速运动组合公式）
· 综合分析 = 气泡上浮判 D（综合等温 + 液体压强 + 第一定律推吸热）

🧠 大类 3: 思维任务 (输出)

6设问开放度 (openness · 3 档 · 扩展 v1 的 is_open)
题目设问的封闭程度。反映答案的唯一性和解题路径的多样性。
  • 封闭: 答案唯一 · 解题路径基本唯一 · 大部分选择题
  • 半开放: 答案唯一但解题路径可多样 · 或需要选取合适分析角度 · 大题主问常见
  • 完全开放: 需要学生自选建模路径 · 结论可以有多种表述 · 大题最后小问常见
7建模复杂度 (modeling · 4 档 · 承接 v1)
从真实情境抽象、简化、组合物理系统的操作过程。聚焦"把文字场景翻译成理想化模型的加工工作量"（杨老师 18:35）· 独立于知识深度。
  • 0: 题目已给全部理想化条件 · 学生不需要建模
  • 1: 需要选择合适模型 · 但候选很少
  • 2: 需要抽象出关键假设 · 排除干扰因素
  • 3: 需要从头建模 + 数学构造（自主选择物理系统的边界、变量、假设）
示例:
· 0 = 大部分选择题（题目已给全条件）
· 1 = 平抛运动小车（选水平/竖直分解模型）
· 2 = 天宫霍尔推进器（需要抽象出"动量守恒 + 微小推力持续作用"模型）
· 3 = 变力做功题最后小问（需自主选择微元法/图像法建模）
8推理链长度 (reasoning · 5 档 · 承接 v1)
从已知条件到物理方程 · 需要几步逻辑判断、过程拆分、规律选取。关注思维步骤 · 不涉及数值 / 符号计算（杨老师 18:41）· 独立于运算难度。
  • 1: 一步推出结论
  • 2: 两步推理
  • 3: 三步推理 · 需分过程或用临界条件
  • 4: 四步推理 · 需多个规律串联判断
  • 5: 五步以上 · 或需要多次回溯、假设、验证
示例:
· 推理 = 3（气泡上浮: 恒温 → 内能不变 → 排除 A · 深度减 → 压强减 → 排除 B/C · 得 D 需第一定律）
9运算难度 (computation · 4 档 · v2 新增)
数学处理操作的复杂度。仅看列式后的计算工作量 · 和逻辑推导无关（杨老师 18:41）· 独立于推理链长度。
  • 无运算仅定性: 只需定性判断大小 / 方向 / 变化 · 无数值计算
  • 简单数值运算: 一两步代数 / 单位换算
  • 中等多步运算: 联立方程 / 几何分解 / 三角函数
  • 复杂推导运算: 微分 / 积分 / 多参推演 / 复杂几何优化
示例:
· 无运算仅定性 = 气泡上浮判 D（只判方向 · 无计算）
· 简单数值 = 汽车匀减速求距离（一步公式代入）
· 中等多步 = 带电粒子在场中偏转（联立力 + 运动学 + 几何）
· 复杂推导 = 变力做功微元求积分
10题型因素 (question_type · 3 类)
题型对得分方式的影响。北京物理高考试题主要 3 类。
  • 选择题: 4 选 1 · 有猜测下限 25% · 支持排除法
  • 填空题: 需给出具体数值 / 表达式 · 常见于实验题 15 / 16 小问
  • 解答题: 需完整推理和计算过程 · 大题 17 到 20 的主问
